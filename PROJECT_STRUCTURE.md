# Estructura del Proyecto - Modelamiento Dinámico

## 📂 Organización de carpetas

```
Modelamiento_dinamico__/
├── front/                          # Frontend - Aplicaciones web
│   ├── modulo-02/                 # Módulo 02: Ingeniería Inversa POT
│   │   ├── index.html             # Página principal
│   │   ├── assets/
│   │   │   ├── css/               # Estilos
│   │   │   └── js/                # Scripts
│   │   └── README.md
│   └── ...
├── backend/                        # Backend - Servidores y APIs
├── apis/                           # Endpoints de API
├── data/                           # Datos y datasets
├── docs/                           # Documentación general
│   ├── MODULO-02.md               # Doc del Módulo 02
│   └── ...
├── .github/                        # Configuración de GitHub
├── tools/                          # Herramientas y utilidades
├── qa/                             # Control de calidad
├── qa-reports/                     # Reportes QA
├── mobile-audit/                   # Auditoría mobile
├── index.html                      # Página de inicio principal
├── scripts.js                      # Scripts globales
├── style.css                       # Estilos globales
├── category-items.js               # Catálogo de ítems
└── README.md                       # Documentación principal

```

## 🗂️ Descripción de carpetas

### `front/`
Aplicaciones frontend y módulos interactivos.
- **modulo-02/** - Visualización de red del POT

### `backend/`
Servicios backend y lógica de servidor.

### `apis/`
Endpoints y rutas de API REST.

### `data/`
Datos, datasets y archivos de configuración.

### `docs/`
Documentación de módulos y guías técnicas.

### `tools/`
Utilidades y herramientas de desarrollo.

### `qa/`
Scripts y planes de testing.

### `qa-reports/`
Reportes de calidad y validación.

### `mobile-audit/`
Auditoría de compatibilidad mobile.

## 📋 Archivos principales

- **index.html** - Página de inicio principal
- **scripts.js** - JavaScript global
- **style.css** - Estilos globales
- **category-items.js** - Catálogo de categorías

## 🚀 Cómo empezar

1. **Frontend:** Abre `index.html` en el navegador
2. **Módulos específicos:** Navega a la carpeta `front/` para ver los módulos
3. **Documentación:** Consulta `docs/` para información detallada

## 📝 Notas

- Cada módulo debe tener su propia carpeta bajo `front/`
- Los estilos se organizan en `assets/css/`
- Los scripts van en `assets/js/`
- La documentación debe actualizarse en `docs/`
