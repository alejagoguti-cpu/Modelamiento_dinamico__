## Redes de Retroalimentación (Ciclos de Refuerzo)

### 🔴 CICLOS DE REFUERZO POSITIVO (Amplificación)
Estos ciclos AMPLIFICAN cambios (pueden ser buenos o malos)

#### Ciclo de Recuperación (Saludable)
```
Más flores → Más abejas → Más polinización → Más flores
    ↑________________________________________________________________↓
```

#### Ciclo de Colapso (Degradación)  
```
Contaminación → Invasoras prosperan → Nutrientes se agotan → Flores mueren → Abejas mueren → Aves mueren → Colapso total
    ↑_________________________________________________________________________________________________↓
```

#### Ciclo de Invasión Acuática
```
Agua contaminada → Buchón prospera → Consume nutrientes → Flores terrestres mueren → Abejas sin alimento → Aves sin presas
    ↑________________________________________________________________________________________________↓
```

### 🟢 CICLOS DE RETROALIMENTACIÓN NEGATIVA (Estabilización)
Estos ciclos ESTABILIZAN el ecosistema (mantienen equilibrio)

#### Control de Poblaciones por Predación
```
Muchas abejas → Más aves → Más depredación → Pocas abejas → Menos aves → Recuperación de abejas
    ↑_________________________________________________________________________________________↓
```

#### Regulación Estacional
```
Verano (calor) → Reproducción máxima de abejas → Más competencia → Recursos escasos → Invierno (frío) → Menos reproducción
    ↑__________________________________________________________________________________↓
```

#### Nutrientes-Microorganismos
```
Microorganismos activos → Más nutrientes → Flores crecen → Biomasa muere → Más descomposición → Más microorganismos
    ↑_______________________________________________________________________↓
```

## Interacciones de Múltiples Especies

### Triángulo Depredador-Presa-Recurso

```
        FLORES (Recurso)
           /    \
          /      \
         /        \
    ABEJAS    ←→   AVES
   (Presa)      (Depredador)
   
Dinámicas:
- Pocos recursos (flores) → Abejas débiles → Aves desaparecen → Recuperación de flores
- Muchos recursos → Abejas abundantes → Aves abundantes → Depredación intensa → Ciclo
```

### Competencia de Múltiples Herbívoros

```
    │                      ├─ Suministrado por Microorganismos

    │
PLANTAS ACUÁTICAS (Buchón)
```

## Ejemplos de Cascadas Ecológicas Emergentes

### Escenario 1: Contaminación del Agua + Invasoras Acuáticas
```
1. Usuario presiona W (contamina agua)
2. Calidad agua cae 30%
3. Buchón (plantas acuáticas) prospera
4. Buchón >30 → consume nutrientes del suelo
5. Nutrientes bajan → Microorganismos bajan
6. Flores terrestres mueren (sin nutrientes)
7. Abejas sin comida → mueren
8. Aves sin presas → desaparecen
9. Sistema de polinización colapsa
10. RESULTADO: Humedal muere, dominado por invasoras acuáticas
```

### Escenario 2: Explosión de Abejas + Control Depredador
```
1. Usuario presiona ↑↑↑ (agrega 15 abejas)
2. Mucha polinización → flores se reproducen
3. Más flores → más alimento → aves aparecer
4. Aves cazan abejas (depredación)
5. Abejas se estabilizan en cifra media
6. Aves se estabilizan  
7. Equilibrio dinámico: ciclo predador-presa
8. RESULTADO: Ecosistema resiliente y variado
```

### Escenario 3: Contaminación Simultánea + Invasoras
```
1. Usuario presiona W + A (agua + aire contaminados)
2. Invasoras terrestres + acuáticas proliferan
3. Compiten agresivamente por nutrientes
4. Microorganismos bajan (agua contaminada)
5. Nutrientes se agotan rápidamente
6. Flores nativas no pueden competir
7. Abejas sin alimento
8. Aves sin presas
9. Ocupación del hábitat >90% (solo invasoras)
10. RESULTADO: Conversión total a ecosistema invasor
```

## Conclusión

Este sistema modela una red ecológica compleja donde:

1. **Los comportamientos locales crean efectos globales**: Un cambio pequeño en abejas (↑↓) afecta todo el ecosistema
2. **Hay sorpresas emergentes**: Interacciones inesperadas (insectos comen microorganismos → colapso)
3. **Múltiples vías de colapso**: Contaminación agua, aire, invasoras, degradación nutrientes
4. **Resiliencia variable**: El ecosistema puede recuperarse de algunos impactos pero no de otros
5. **Puntos de no retorno**: Hay umbrales críticos donde el sistema cambia irreversiblemente
